Methods & research notes

Included methods

Word tokenization; stopword filtering; frequencies; type-token ratio; concordance; relative-frequency trends; n-grams; proximity collocations; dictionary sentiment; TF–IDF cosine similarity; capitalization-based entity candidates; sentence co-occurrence networks.

Not included in this offline edition

True POS tagging, lemmatization, spaCy NER, VADER sentiment, transformer inference, and LDA topic modeling. These require larger language resources or a separate integration.

Data privacy

All processing runs locally in the browser. Uploaded texts are not sent to an application server. CDN-free and no API keys required.

GitHub Pages deployment

Upload index.html to a GitHub repository. Open Settings → Pages → Deploy from branch → main / root. Your published site will serve this file automatically.

Pedagogy

Automated results are exploratory evidence, not substitutes for close reading. Short samples are especially vulnerable to misleading lexical statistics.
